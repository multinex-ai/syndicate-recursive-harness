# Local Syndicate Wan 2.1 Base Assets

This repository is a pinned redistribution mirror of the Wan 2.1 VAE and tokenizer assets used by Local Syndicate Harness². The files come from `Wan-AI/Wan2.1-T2V-1.3B` at revision `37ec512624d61f7aa208f7ea8140a131f93afc9a`.

These assets are only part of the local video pipeline. The installer combines them with a separately licensed checkpoint and UMT5 encoder, verifies every file against the public manifest, and runs a smoke check before activation.

This mirror preserves upstream attribution and does not claim authorship of Wan 2.1.
