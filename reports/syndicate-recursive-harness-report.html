01 Inception & Charter

IMPLEMENTED LOCALLY

The product boundary is now real: the public harness is independent of any proprietary downstream consumer application.

Problem

A user should not need to understand Rust, Node, Python environments, MLX, model shards, hashes, or context windows. They should install the small program, select a model pack, and receive a readable health receipt.

Users

Developers and creators with Apple Silicon who want a local recursive agent team for chat, code, browser/desktop work, images, and video.

Success

Fresh Mac → install → model download → agents-chat → Qwen answer → routed specialist job → evidence receipt, with rollback and repair.

Non-goals

No bundled credentials, silent macOS permission grants, unrestricted agent messaging, hidden chain-of-thought, unlicensed weight mirroring, or proprietary downstream source in the public repository.

Constraints and spending

Current target: Apple Silicon first. Models are large and download separately. One heavy model may run at a time. No paid resource or hosted inference is authorized by this report. Tracking references: public harness issue pending exact-copy approval.

Transparency and recovery contract

The action ledger records timestamps, selected route, declared reason, tool or model start/result, retry count, output receipt, and error class. It does not publish private chain-of-thought. Recovery is detect → bounded retry or signed rollback → health check → evidence receipt. It never silently changes policy, licenses, providers, or credentials.

The installer cannot grant Accessibility or Screen Recording silently. 09 Operate & Track

LOCAL ONLY

Automatic handoffs and repair are bounded, observable, and reversible; no hidden permission handoff is required inside an already approved route.

Implemented

SQLite jobs, cancellation, deadlines, a machine-wide heavy-model lock, deterministic compaction, hash-verified downloads, quarantine, resumable partials, retry ceilings, action-ledger JSONL, and evidence envelopes.

Context safety

The 16,384-token window begins compacting at 10,800, hard-stops at 14,300, reserves 2,048 for output, and budgets 1,600 for skills. It preserves the latest task and linked tool calls/results; an oversized latest task is rejected instead of silently truncated.

Lock parity

Rust, Python, and the installer trim absolute lock overrides and reject relative overrides consistently, so every packaged adapter resolves the same machine-wide lock.

Needed

Signed release channel, atomic activation pointer, real update/rollback/uninstall rehearsal, redacted support bundle, clean-machine acceptance, and release telemetry.

Downstream application boundary

External applications remain independently versioned and consume this harness solely through the versioned CLI and MCP contracts (SYNDICATE_HARNESS_HOME or PATH).
